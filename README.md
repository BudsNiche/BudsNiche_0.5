# BudsNiche Full Site v4

This folder contains the complete 5-file BudsNiche site for a fresh GitHub repository.

## Upload all 5 files exactly as named
- index.html
- styles.css
- script.js
- favicon.svg
- README.md

Do not rename index.html, styles.css, or script.js.

## What is working in this version
- Daily content loaded from Supabase
- Bible verse / motivation / fact / hot take / daily question
- Real shared Hot Take voting
- Daily discussion board
- Public answers and replies
- Daily discussion resets visually by date while old posts stay stored
- Daily game topics loaded from Supabase
- Check-in streak stored in the browser
- Prototype scoring for the current demo game topics

## Fresh repository setup
1. Create a brand-new GitHub repository.
2. Upload all 5 files from this folder to the main/root of the repository.
3. Import that repository into a new Vercel project.
4. Deploy.
5. Use the new Vercel production URL for testing.
