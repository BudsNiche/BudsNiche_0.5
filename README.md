# BudsNiche V20 — Final Dark Ames Community Feed

This is the finalized V20 cosmetic pass built on top of the existing V19/V20 functionality.

## What changed visually
- Dark charcoal-gray site background (not pure black)
- Compact community-portal header with circular BN mark
- Clearly separated center feed
- Side widgets use one shared dark utility style so they do not compete with the feed
- Ames masthead and "Ames, today" issue module
- Mature, deep-color feed posts rather than pastel cards
- Boxier borders, tighter spacing, smaller metadata and classic community-site details
- Mobile hamburger drawer still exposes the side widgets
- Game remains its own separate lobby/view after the daily feed

## Functionality intentionally preserved
- Supabase daily content
- Hot Take voting
- This or That voting
- Discussion/replies
- Niche AI Judge via `bright-action`
- Judge training/cache system
- Ranked List support via `match-list`
- Existing game timer and scoring flow

Upload the root files together to GitHub so the HTML/CSS/JS stay matched.
